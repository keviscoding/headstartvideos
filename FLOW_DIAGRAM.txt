┌─────────────────────────────────────────────────────────────────────────┐
│                         KEY INSIGHTS                                    │
└─────────────────────────────────────────────────────────────────────────┘

1. The recipe DB column is NOT read by cook_runner
   - It's only for DB queries/filtering
   
2. hydrate_job_from_row only copies request_json
   - It never looks at the recipe column
   
3. run_cook_job reads recipe from job["request"]
   - This comes from request_json, not the column
   
4. Missing recipe defaults to "animated_explainer"
   - Line 126: recipe = ... or "animated_explainer"
   
5. The /api/build endpoint already does this correctly
   - It includes recipe in the request payload
   - Avatar endpoint was the outlier
