CHANNELRECIPE STUDIO · SETUP

A few connections.
Then your first video.

Four steps: check your computer, connect your ChannelRecipe account, sign in to Claude, and connect a media account for voice and images. Stuck? Open this folder in Claude Code and ask it to finish setup, or ask us in Discord.

A newer version of Studio is available. Finish any video that’s running and close the launcher, then open this folder in Claude Code and say “Update ChannelRecipe Studio”, or run cr_update.py with the studio’s Python. Your projects and settings stay put. Don’t download a fresh copy into a new folder.

01 / CHECK YOUR COMPUTER

Make sure the tools are ready

Checking your setup…

A tool is missing. How do I fix it?

Open this downloaded folder in Claude Code and ask: “Help me complete the ChannelRecipe setup checks.” It will guide you through the missing free tools.

On Mac with Homebrew: brew install ffmpeg-full node. FFmpeg must include subtitle support (libass), H.264 and audio encoders. On Windows: install a full FFmpeg build and Node, then close and reopen the launcher. Your system PATH needs to include FFmpeg.

Advanced media settings

Narration

Choose which account and voice model reads your scripts. Through Kie.ai you can use Gemini or ElevenLabs voices without a separate ElevenLabs key. This overrides narration from the key above.

This voice replaces recipe voices. Private clones do not transfer between accounts. A new key replaces the saved key for that provider.

Image models and backups

Pick a first image model and backups through Kie.ai. If one model fails or refuses a scene, Studio tries the next with the same description and references.

Up to five attempts per image, once per selected model. Backups run only after a confirmed model failure or refusal. Balance, access, rate limits and uncertain requests stop the job. Each attempt may use credits; newer models use 1K output to limit cost. Successful images and provider task IDs are saved for resume.

Add individual accounts or extra services
