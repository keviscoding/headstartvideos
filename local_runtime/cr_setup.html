    BEFORE YOU START

    Make sure the tools are ready

    Checking your setup…

    A tool is missing or the network blocks something. How do I fix it?

    Network: a blocked service is usually a firewall, antivirus, VPN or the internet provider. Allow the address shown, or try another network (a phone hotspot works), then press Check again. Where Studio has a way around a block it says so, and you can carry on.

    Open this downloaded folder in Claude Code and ask: “Help me complete the ChannelRecipe setup checks.” It will guide you through the missing free tools.

    Video tools (FFmpeg) or YouTube helper (Node.js) missing? Press Fix it next to it: Studio downloads a fixed version into its own folder, checks its fingerprint and that it works. No password, and any copy you already have stays as it is. Python is the one tool Studio can’t install: the launcher needs it first and says what to do.

    Prefer to install them yourself? On Mac with Homebrew: brew install ffmpeg-full node (FFmpeg must include subtitles, H.264 and audio encoders). On Windows: winget install -e --id Gyan.FFmpeg and winget install -e --id OpenJS.NodeJS.LTS. Then close and reopen the launcher.

    Optional: render in the cloud, on your own Modal account

    Studio can render your videos on a cloud machine instead of this computer. It runs on your own Modal account (modal.com), so Modal bills you directly for the machine time, by the second. Your computer stays free and several videos render at once. It isn’t faster for one short video: the script, voice and pictures are still made here with your Claude Code first, and a machine takes a few minutes to start.

    What it costs on Modal: about $0.63 an hour for the normal machine and $1.43 an hour for the one with a graphics card (3D). Measured on 1-minute videos: a picture recipe about 4 minutes of machine time (about $0.04), a footage documentary about 17 minutes (about $0.18), a 3D video about 19 minutes on the graphics card (about $0.45). Modal’s free plan includes monthly credits that are used first. Your voice, pictures and Claude are paid as usual, on your own accounts.

    1. Make a Modal account.Sign up free at modal.com (Google or GitHub sign-in is fine).
      Open Modal ↗
    2. Only for 3D: add a card.Modal’s machines with a graphics card (3D recipes, 3D clones) only start once a card is on your Modal account: Modal → Settings → Usage and billing. Other videos use your free monthly credits first.
    3. Create a token.In Modal open Settings → API Tokens and press New Token. Modal shows a Token ID (starts with ak-) and a Token secret (starts with as-) once. Copy both.
      Open API Tokens ↗
    4. Paste both here.Studio checks them with Modal and sets up its cloud storage on your account. The token stays on this computer (and on your own Modal machines).
    5. Choose Studio Cloud when you create.In Create, under Where it renders, choose Studio Cloud. Your first cloud video also sets up Studio’s machines on your Modal account (about 5 to 10 minutes, once). Keep Studio open while it renders: the machine asks your Claude Code its questions.

    Finished cloud videos stay in your Modal storage until you delete them (Projects, Your cloud renders). Shorts, Ranking Shorts, FOLIO, your own recording and recaps from your own panels render on this computer.

    Troubleshooting: a video stopped

    If a video stopped (for example, Claude hit its usage limit), everything it finished is saved. Check your Claude usage and make sure nothing is running, then review it here.
